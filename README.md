# 市政道路施工封路方案协调与审批平台

源提示词编号：11。支持分段封路范围、施工阶段、绕行路线、车道收窄和临时设施的同一地图协作；检查相邻工程、救护通道、公交覆盖和绕行时延冲突；提供图层开关、路线绘制、阶段时间轴、条件会签、版本比较和公开通告包导出。

## 方案版本机制

封路范围、绕行路线、会签条件挂在**同一个方案版本**上（`src/versioning/`）：

- **统一版本**：每次变更对阶段 / 绕行 / 会签条件整体快照生成新版本，实体携带 `versionAnchor`。
- **级联重算**：某段调整后，该段的公交覆盖、绕行时延、救护通道、相邻工程四项检测立即失效并按当前方案重算；其他单位的会签确认结果保留（锚点过期的确认会标记“需复核”而不清除）。
- **并发冲突**：提交会签条件需携带起草时的基准版本；两家单位同时提交同一条件（分段 + 主题）时先到者生效，后到者拿到冲突并保留现场，可基于最新版本重新提交为补充意见。
- **版本恢复**：复核失败后按版本号恢复，以历史快照生成新的头版本，历史不丢。
- **旧数据迁移**：没有版本锚点的旧数据（含旧 localStorage）按原有内容迁移成首版 v1。

引擎为纯函数（`versioning/engine.ts`），可独立验证：

```bash
npm run verify
```
